# L2R preparation smoke-test videos

`videos/moving_shapes.mp4` and `videos/color_waves.mp4` are procedurally
generated by `generate_sample_videos.py`. They contain no downloaded or
third-party footage.

These two clips are deliberately tiny examples for checking that
`early-failure-prepare-l2r` can create a paired latent/RGB manifest. They are
**not a training dataset**, and a model trained on them will not be useful.
The research dataset and its prepared manifest are not distributed.

To recreate the checked-in clips:

```bash
python examples/l2r_training/generate_sample_videos.py
```

See [`docs/L2R_TRAINING.md`](../../docs/L2R_TRAINING.md) for the complete data
preparation, factorized training, fusion, and strict-load workflow.
