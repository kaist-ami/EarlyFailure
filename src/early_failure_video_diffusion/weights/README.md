# Bundled L2R checkpoints

These small inference-only checkpoints are distributed with the repository and
Python package:

- `deploy_fused_crf18_cogvideox.pt`
- `deploy_fused_crf18_wan1.5B.pt` (used by the Wan2.1-1.3B backend; the original
  research filename is retained for compatibility)

See `SHA256SUMS` for integrity hashes. Optional L2R training and fusion commands
are documented in the repository's `docs/L2R_TRAINING.md`; the research dataset
and prepared manifest are not distributed.
